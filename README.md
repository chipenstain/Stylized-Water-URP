# Описание
Всем привет! Этот репозиторий - это улучшенная версия шейдера от [ameye.dev](https://ameye.dev/notes/stylized-water-shader/). Мной было добавлено маскирование воды, для поддержки полых плавающих объектов. Также он был скомпонован с шейдеров от [@Parrot222](https://github.com/Parrot222) из [этого репозитоия](https://github.com/Parrot222/Unity-Water-Shaders) для создания реакции на взаимодействие с водой.

# Инструкция
1. На плоскость водоёма наложить материал ```Water``` добавить ```Ripple Effect``` В нем указать размер ```RenderTexture```, ссылку на неё, и применить шейдеры ```RippleShader``` + ```Add``` Слой для воды - ```Water```.

2. Для маскирования воды наложить на меш-маску Unlit материал с зеленым цветом и присвоить слой ```WaterMask```.
Создать ```RenderTexture``` с размерами экрана. И рендерить в неё в с копии ```MainCamera``` камеры с слоями ```Water``` и ```WaterMask```. Эту текстуру присвоить в материал воды. Готово, в воде на месте маски создаются просветы.


3. Создать камеру для ряби. 
- Ортографик
- Размер - под водоём.
- Смотрит вертикально вниз. 
- Маска на слой с частицами. 
- Рендерить в 'RenderTexture'.

Создать частицы, с отдельным слоем, которые будет видеть наша камеры. Это эпицентры ряби. Каждое появление партикла - одна рябь.
